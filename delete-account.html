1. 계정 삭제를 요청하는 방법

아래 두 가지 방법 중 편한 쪽으로 요청하시면 됩니다.

방법 1 — 앱에서 직접 삭제 (팀 관리자)

  • 오늘몇공 앱을 실행하고 사장님(관리자) 계정으로 로그인합니다.
  • 하단 메뉴에서 인력관리를 엽니다.
  • 삭제할 직원 카드를 누른 뒤 ‘회원 탈퇴(삭제)’ 버튼을 누르고 확인합니다.
  • 해당 직원의 계정과 기록이 삭제됩니다.

방법 2 — 운영자에게 요청 (본인 계정)

본인 계정을 직접 삭제하려면 아래로 요청해 주세요. 가입에 사용한 이름과 휴대폰 번호를 적어 보내시면 됩니다.

2. 삭제되는 데이터

  • 계정 정보: 이름, 휴대폰 번호, 비밀번호(4자리), 소속 업체(팀) 정보
  • 프로필 정보: 직종, 경력 연수, 기본 일당, 담당 현장
  • 이용 기록: 출근·공수 기록, 메모, 월별 정산에 사용된 기록
  • 소통 기록: 팀 채팅 메시지와 첨부파일, 광장 게시글·댓글
  • 광고 식별자(AD_ID)는 앱 삭제 또는 기기 광고 설정 초기화로 더 이상 사용되지 않습니다.

이미 다른 이용자에게 전송되어 상대방 대화 화면에 표시된 메시지는 상대방 대화 기록에 남을 수 있으며, 운영자는 삭제 요청 시 해당 내용에 작성자 정보가 노출되지 않도록 확인합니다.
